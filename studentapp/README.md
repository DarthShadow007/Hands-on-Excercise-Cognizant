# Student App Dashboard

## Overview
This is a modular React application built to demonstrate the foundational structure of React Class Components. 

## Features
* **Class-Based Architecture:** Utilizes React's `Component` class for UI rendering.
* **Component Modularity:** Separates UI concerns into distinct components (`Home`, `About`, `Contact`).
* **Clean UI:** Implements basic inline CSS for structured, readable dashboard cards.

## How to Run
1. Ensure Node.js is installed.
2. Navigate to the project directory in your terminal.
3. Run `npm install` to ensure dependencies are loaded.
4. Run `npm start` to launch the local development server at `http://localhost:3000`.
