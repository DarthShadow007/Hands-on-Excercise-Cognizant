# Cognizant Hands-On Exercises — Java Engineering & Design Patterns

## 📌 Repository Overview
Welcome to the **Cognizant Hands-On Exercises Repository**! This repository serves as a comprehensive portfolio of practical software engineering assignments designed to master **Core Java**, **Creational Design Patterns**, **Data Structures & Algorithms**, and **Recursive Mathematical Modeling**.

## 🚀 Quick Start & Setup Guide

### 1. Prerequisites
Ensure you have the **Java Development Kit (JDK 21+)** installed and configured in your system environment variables (`JAVA_HOME` and `PATH`).

### 2. Opening in VS Code
1. Clone or download this repository to your local machine.
2. Open **Visual Studio Code** and select `File > Open Folder...` to open the root folder (`HANDS ON EXCERCISE COGNIZANT`).
3. Allow the **Extension Pack for Java** to initialize the language server and build paths.

### 3. Running Individual Exercises
* Navigate to any exercise folder in the left **Explorer** sidebar.
* Open the driver class containing the `public static void main(String[] args)` method.
* Click the clickable **Run** link appearing directly above the `main` method (or use **Ctrl + F5**).
* View output verification in the **TERMINAL** tab at the bottom of the editor.

---

## ⚙️ Troubleshooting & Tip for VS Code
If you encounter workspace errors such as `Project missing required source folder` or package declaration mismatches after renaming folders:
1. Open the Command Palette (`Ctrl + Shift + P`).
2. Type and select: **`Java: Clean Java Language Server Workspace`**.
3. Click **Restart and Delete** to refresh the IDE build cache cleanly.
