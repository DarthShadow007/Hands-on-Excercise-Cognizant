# Event Examples App

## Overview
A React functional component application designed to demonstrate the implementation of core React synthetic events.

## Features
* **onClick Handling:** Demonstrates how to bind click events to trigger functions.
* **onChange Handling:** Shows how to capture user input in real-time.
* **State Hook (`useState`):** Utilizes React state to dynamically update the UI based on text input changes.

## How to Run
1. Navigate to the project directory in your terminal.
2. Run `npm install` to load dependencies.
3. Run `npm start` to launch the app at `http://localhost:3000`.
