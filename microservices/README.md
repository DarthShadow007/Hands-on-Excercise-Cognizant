# Spring Boot Microservices: Account & Loan Services

This directory contains two decoupled, lightweight RESTful microservices designed for a banking context: an **Account Microservice** and a **Loan Microservice**. Each service operates as a standalone Spring Boot application running on its own dedicated HTTP port.

## 📁 Directory Structure

```text
microservices/
├── account/     # Account Microservice (Runs on Port 8080)
└── loan/        # Loan Microservice (Runs on Port 8081)
