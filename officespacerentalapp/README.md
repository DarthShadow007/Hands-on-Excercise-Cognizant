# Office Space Rental App

## Overview
A React application that demonstrates JSX execution, array iteration, and conditional inline styling based on rental pricing tiers.

## Features
* **JSX Expressions:** Dynamically formats and renders JavaScript objects directly inside JSX layout structures.
* **Conditional Styling:** Dynamically alters card background and text colors based on rental thresholds.
* **Flexbox Layout:** Displays real estate cards using dynamic CSS mapping.

## How to Run
1. Navigate to the project directory in your terminal.
2. Run `npm install` to ensure dependencies are loaded.
3. Run `npm start` to launch the local development server at `http://localhost:3000`.
