# Counter State App

## Overview
A React application demonstrating numerical state management and dynamic inline CSS rendering based on state conditions.

## Features
* **useState Hook:** Manages numerical state variables (`count`).
* **State Updates:** Uses inline arrow functions inside `onClick` events to increment, decrement, and reset the counter.
* **Dynamic Styling:** Conditionally renders text color based on whether the counter value is positive, negative, or zero.

## How to Run
1. Navigate to the project directory in your terminal.
2. Run `npm install` to load dependencies.
3. Run `npm start` to launch the app at `http://localhost:3000`.
