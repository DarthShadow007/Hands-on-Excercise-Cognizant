# Cricket App

## Overview
A React functional component application built to showcase ES6 JavaScript features including `.map()`, `.filter()`, arrow functions, and object destructuring.

## Features
* **ES6 Map & Filter:** Filters players based on score criteria and maps over arrays to construct dynamic UI lists.
* **Object Destructuring:** Unpacks object properties (`id`, `name`, `runs`, `team`) directly inside iteration callbacks.
* **Functional Formatting:** Uses arrow functions to maintain clean, readable transformation logic.

## How to Run
1. Navigate to the project directory in your terminal.
2. Run `npm install` to load dependencies.
3. Run `npm start` to launch the app at `http://localhost:3000`.
