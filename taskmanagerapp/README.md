# Task Manager App

## Overview
A comprehensive React application demonstrating CRUD (Create, Read, Update, Delete) operations using array state manipulation.

## Features
* **Array State Management:** Uses `useState` to maintain an array of task objects.
* **Immutability:** Employs the spread operator (`...`) and `.map()`/`.filter()` methods to update state immutably.
* **Dynamic Styling:** Conditionally strikes through and dims text based on the `completed` boolean of each task.

## How to Run
1. Navigate to the project directory.
2. Run `npm install`.
3. Run `npm start`.
